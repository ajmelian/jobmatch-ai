# v1.3.0 — Candidate-neutral specification

**Status:** public specification draft. The existing v1.2.0 is retained unchanged.

## Changes

- Added session input contract with generic CV and job-offer placeholders.
- Added explicit privacy boundaries between candidates.
- Added language and regional variables.
- Clarified absence of actual multi-agent orchestration or employer ATS integration.
- Added requirements to avoid protected-characteristic inference and automated hiring decisions.
- Preserved v1.2.0 scoring, evidence veto and final-document quality gates in the derived version.
